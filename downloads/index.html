Downloads

Every tool works from your own disk without this website. Download the files, then open the index.html of a tool.

All tools

Download everything as a .zip (straight from GitHub). Unzip it and open index.html. The links between tools work offline too.

Single tools

  1. Text Diff: index.html, app.js, style.css. Put all three in one folder.
  2. Metal Holdings: one file. Browsers block the price lookups from pages opened as file://, so serve the folder locally: python3 -m http.server inside it, then open http://localhost:8000. Data saved in the browser belongs to the address you use, so move it with a save code.
  3. Bundle Editor: one file (still password protected).
  4. Conflict Resolver (browser): needs the Text Diff files too. Use the .zip above, or keep the folder layout projects/conflict-resolver/ next to projects/diffchecker/.

Conflict Resolver for the desktop

A Python/Tkinter app with the same diff engine. It also merges KeePass .kdbx databases through keepassxc-cli, which a browser can't do. Needs Python 3.8+.

  1. resolve_conflicts_gui.py
  2. README.md (requirements and options)

Run it with python3 resolve_conflicts_gui.py, or with a folder path as the argument.
