Check that nothing is sent

You don't have to take my word for it. Your browser can show every request a page makes:

  1. Open a tool, then open the developer tools: F12 or Ctrl+Shift+I (⌘+⌥+I on a Mac). In Safari, first turn on Settings → Advanced → Show features for web developers.
  2. Go to the Network tab, tick Preserve log, and reload the page.
  3. Use the tool as normal. Only the page's own files (index.html, .js, .css) should appear. Nothing should be sent as you type, load files or save.
  4. Want a stronger test? Load the page, set the Network throttling dropdown to Offline (or unplug), and keep working. Everything still runs.

The one exception is Metal Holdings. It fetches spot prices from api.gold-api.com and exchange rates from api.frankfurter.dev. Those requests don't include your holdings, and you'll see them in the list. The source of every page is readable with Ctrl/⌘+U, or on GitHub. To be fully independent of this site, download the tools and open them from your own disk.
