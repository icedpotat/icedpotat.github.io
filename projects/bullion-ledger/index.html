Value over time

A snapshot of your total value is recorded automatically each time prices refresh (at most once per day), shown here in the current Spot/Worth mode and currency. There's no free source for genuine historical gold/silver prices, so the chart can't be reconstructed after the fact — it only grows forward from whenever you start using the app. You can add a past point by hand below if you already know an earlier value.

Worth premiums

"Worth" value adds a percentage on top of spot price, by form — a rough stand-in for realistic resale or replacement cost.

Backup & restore

Local storage is tied to this browser. A save code is the only way to recover your holdings elsewhere, or after clearing browser data — keep one somewhere safe (a notes app, a password manager, a text file).

Prices from gold-api.com and the Frankfurter (ECB) exchange-rate API. Nothing leaves this device except those two public, anonymous price lookups.
